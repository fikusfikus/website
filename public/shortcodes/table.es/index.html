Tablas

Por defecto, las tablas generadas con la sintaxis de markdown no son responsive, para solventar un poco este problema, encierra tus tablas con este shortcode.

Sintaxis # 

{{< table >}}
...table
{{< /table >}}

Opciones #

  • Get 0: Clases adicionales CSS. (opcional)

Ejemplo # 

{{< table >}}
| Syntax | Description |
| --- | ----------- |
| Header | Title |
| Paragraph | Text |
{{< /table >}}
Syntax Description
Header Title
Paragraph Text
